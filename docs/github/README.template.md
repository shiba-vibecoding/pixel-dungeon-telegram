**Pixel Dungeon для Telegram** — классический рогалик Watabou, выросший до Shattered Pixel Dungeon v4: шесть классов, таланты, алхимия, подземелье дня с рейтингом. Открывается прямо в Telegram, ничего не нужно ставить.

<p align="center">
  <img src="docs/github/screens-ru.png" alt="Привал, подземелье, таланты, алхимия" width="100%">
</p>

## Что внутри

- **Шесть классов**: Воин, Маг, Разбойник, Охотница, Дуэлянтка, Клирик.
- **Таланты** на четырёх ярусах, путь мастерства и способность брони.
- **Алхимия**: котёл, энергия, особые зелья, заклинания и безделушки.
- **Подземелье дня**: одно на всех, одна попытка, кубки за 1–3 место; недельная доска с медалями.
- **Привал** — живой главный экран: ваш герой у костра, облики и эффекты из Пиксель-Марта.

## Как играть

Откройте бота [@YOUR_BOT](https://t.me/YOUR_BOT) и нажмите «Играть». Забег сохраняется на сервере и продолжается с любого устройства.

## Разработка

```sh
npm install
npm run dev        # клиент и сервер
npm test
```

Дизайн-система — `docs/design/system/` (README, migration.md, карточки компонентов).
