Сцена шапки, превью и «Что нового» собрана из арта живого Привала, а не нарисована заново: камень холма, арка, факелы и земля — из `camp/camp-outdoor-autumn.png`, расширенные в ширину; костёр — `camp/fire.png` в каменном кольце Привала; шесть героев — первая броня из `camp/camp-heroes.png` (листы Shattered v24). Превью 160×80 ×8, шапка 200×67 ×6. Заголовок — логотип «Pixel Dungeon», подзаголовок «Shattered 4.0.2 · в Telegram»; в превью ссылки он в две строки по 48 px, чтобы читался в маленькой карточке Telegram и X. Скрипты — `tools/art/p25_scene.py`, `p25_github.py`, `p25_cards.py`, `p25_badges.py` (шрифт Galmuri11 — путь в `GALMURI`).

Карточки — настоящие скриншоты текущего main при 375×812 (`tools/art/v25-shots.sh`):
1. Привал — свёрнутый лагерь после забега дня: серия, рекорд, место за сегодня.
2. Подземелье — Город дворфов (глубина 17): вурдалаки, элементаль, колдун, монах; два чемпиона в огненной ауре (один — свой, уровня).
3. Таланты — берсерк 13-го уровня, очки трёх ярусов расставлены.
4. Подземелье дня — конец забега с чипом «зачёт»: подземелье дня сыграно ботом против локального сервера (`v25-daily.js`), забег засчитан и проверен сервером. Бот детерминирован — RU и EN падают одинаково.

Плашки — PNG ×2, а не SVG: GitHub не грузит веб-шрифты в SVG. Текст плашек камня — ink (#e8e2c8), «Играть» — синий Telegram, «Подземелье дня» — blood и gold.
