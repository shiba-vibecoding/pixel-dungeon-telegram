Девять испытаний Shattered — `PD.demo.win.challenges9(lang, { on })`.

- Значки `sheet-challenges9.png` (`.pd-ch9`, `--c` 0–8; `.big` — ×2) в порядке Shattered.
- Шапка: «N из 9 · счёт ×1,25ⁿ» (каждое — +25%, перемножаются).
- Два новых — «Вражеские чемпионы» и «Злые боссы» — с меткой «новое» и кнопкой «?» (`.pd-challenge9.info`): у них длинные описания. У остальных строка описания и так полная.
- «?» у «Злых боссов» — окно с боссами (`.pd-boss-list`): портрет из бестиария, имя, что меняется.
- Описания — короткие версии `challenges.*_desc` Shattered, а не PD 1.9: на диете еда втрое слабее, а не пропадает; вера — мой доспех ослабляет броню; запретные руны — вдвое меньше свитков улучшения.
