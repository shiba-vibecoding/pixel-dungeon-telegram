«Сообщить о проблеме» `.pd-report`: строка в настройках (`.pd-linkrow.report`) и кнопка на экране ошибки.

- Поле `.pd-textarea` «Что случилось» (необязательно) с подсказкой-примером.
- Отметка `.pd-check[role=checkbox]` «Приложить журнал забега» и что в нём есть (ходы и действия, версии; без имени и переписки). По умолчанию включена.
- «Отправить» → во время отправки кнопка выключена с точками `.pd-dots` → «Отправлено, спасибо!» с галочкой и превью значка «Охотник за багами».
- Значок «Охотник за багами» выдаётся, когда разработчик подтвердит ошибку; на полке значков — `badge-bughunter.png`.
