Правила дня на «Привале» при длинных названиях.

- «1 попытка · ещё 5 ч» — `<small class="pd-daily-left">` под заголовком «Подземелье дня» (слева от «Спуститься»), а не плашкой в строке правил.
- В строке `.pd-daily-rules` остаются только испытание (красным) и дар (зелёным) — «Фармакофобия» и «Точильный камень» вместе влезают от 360 px, Pharmacophobia + Whetstone тоже.
- Если однажды не влезут — плашки переносятся целиком на вторую строку (`flex-wrap`), слова не рвутся; подробности — по касанию.
