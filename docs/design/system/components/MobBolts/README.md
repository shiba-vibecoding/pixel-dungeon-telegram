Снаряды и лучи монстров. `PD.demo.mobFx(phone, { scene })` — сцены `shamans`, `casters`, `elementals`, `eye`.

| Кто | Чем | Попал |
| --- | --- | --- |
| Красный шаман | шар `mob-bolts` ряд 0, шлейф `#ff6a5a` | слабость |
| Синий шаман | ряд 1, `#6a9aff` | уязвимость |
| Фиолетовый шаман | ряд 2, `#c070ff` | порча |
| Колдун | ряд 3 — тёмный шар, `#8a3a9a` | деградация |
| DM-100 | молния: ломаная из 5 отрезков, отклонение до ±9 px, новая форма каждые 66 мс; синяя 3 px, белая 1 px, вторая тонкая голубая; 300 мс, последний кадр в полсилы | урон, в воде больнее |
| Огненный элементаль | `wand-bolts` ряд 1 (огонь) | горение |
| Ледяной элементаль | `wand-bolts` ряд 2 (мороз) | холод |
| Грозовой элементаль | световой луч `mob-beams` ряд 2, на 60% дальше цели; 1 → 0,66 → 0,33 за 500 мс | урон |
| Элементаль хаоса | ряд 4 — радужный шар | случайное, как проклятая палочка |
| Злой глаз | 1 с копит свет (сиреневые и белые точки сходятся к глазу), потом смертельный взгляд `mob-beams` ряд 1 сквозь героя до стены, 500 мс тремя ступенями | урон всем на линии |

- Шар летит 600 мс, кадры меняются через 90 мс, шлейф — 4 квадрата 2×2 пикселя цвета снаряда с прозрачностью от 0,44 до 0,11.
- Попадание: вспышка 6×6 одним кадром; значок состояния 16×16 ×2 поднимается над героем 5 ступенями по 100 мс и тает; значок 7×7 встаёт в HUD (`.pd-buff i.mob`).
