Кнопка действия `.pd-actind` — как `ActionIndicator` в Shattered. Плитка 52×52 цвета `--ind` (`indicatorColor()`), выемчатые углы, светлый край сверху-слева и тёмный снизу-справа, значок ×2 по центру, число `.pd-actind-n` справа внизу зелёным `#00ff00` (`CharSprite.POSITIVE`). Стоит над панелью справа (`.pd-actind-wrap`), вторая кнопка — над первой (`.r2`).

**Способность оружия Дуэлянтки:**

- Готова — `--ind:#5500bb`, спрайт оружия из `items.png` Shattered, число зарядов.
- Копит заряд — `.charging`: `#444444`, оружие тусклое (`grayscale .8, brightness .6`), «0» серым, внизу полоска `.pd-actind-fill` (`--v` — доля до следующего заряда).
- Прицеливание — `.aiming`, `aria-pressed="true"`: золотая рамка мигает 0,4 / 0,4 с (`--gold` / `--gold-deep`), поверх уголки `aim.png`. Над панелью — подсказка `.pd-aim-toast` «Коснитесь цели. Кнопка ещё раз — отмена.» и «Отмена».

**Чемпион:** вторая кнопка `.pd-actind.swap` 96×52 — слот «в руке», стрелки `swap.png`, слот «запасное» (тусклее). Касание меняет оружие местами, `aria-label="Сменить оружие"`.

**Боевая стойка** (Кольцо силы у Дуэлянтки): `.pd-actind.stance` со значком `DUEL_BRAWL` (large_buffs 65), «выкл» серым; включена — `.on`: зелёная рамка, «вкл».

**Монах:** `#a08840`, усилен — `#aaee22`; значок `hero_icons` 110, число — энергия. Окно `.pd-monk-window`: 5 строк `.pd-monk-ab` — значок `monk-abilities.png`, имя, описание, цена `.pd-energy-pips` (1–5 ячеек). Не хватает энергии — строка тусклая, ячейки красные.

Все остальные кнопки и их цвета — карточка «Кнопки действия».
