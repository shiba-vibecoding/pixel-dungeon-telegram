Подтверждение `.pd-window.narrow.pd-confirm2` (`role="alertdialog"`):

- Вопрос и что будет — по центру.
- `.pd-confirm-row`: два действия в ряд — слева отмена (`.pd-button.quiet`), справа действие глаголом («Выбросить», «Выйти», «Заменить»), не «Да/Нет». Отмена — по ширине слова, действие занимает остальное; подписи переносятся, не режутся.
- Ещё ответы — `.pd-confirm-more` под чертой: строки `.pd-button` на всю ширину («Продолжить забег», «Сохранить и закрыть», «Сдаться, показать итоги»).
- Удержание `.pd-button.hold` — для замены сохранённого забега:
  - `<span class="pd-hold-fill">` + `<span class="pd-hold-text">`, прогресс — `--p` от 0 до 1;
  - пока держат — `.holding`, подпись «Держите…», заливка 12 ступенями за 1,2 с (JS ставит `--p` каждые 100 мс или класс `.anim` для CSS-анимации);
  - отпустили раньше — `--p` в 0 одним кадром;
  - дошло — `.done`: кнопка золотая, «Заменено», через 300 мс окно закрывается;
  - под рядом — подсказка `.pd-hold-hint` «удерживайте 1,2 с»; при reduced motion — 3 ступени.
- Тап без удержания — подсказка мигает один раз, ничего не происходит.
