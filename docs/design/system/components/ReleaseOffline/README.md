- **Нет связи с сервером** `.pd-offline`: значок, «Играйте дальше: забег сохраняется на телефоне. Когда связь вернётся, он дойдёт до сервера и попадёт в рейтинг», «Пока без связи — без рейтинга и почты», «Повторить» (основная), «Играть без связи», автопроверка раз в 20 с.
- В игре без связи — плашка `.pd-net-badge` под HUD: «Нет связи · забег засчитается позже». Когда связь вернулась — тост «Забег дошёл до сервера».
- **Обновление** — тост `.pd-toast.update` со значком, который крутится шагами: «Вышла новая версия — обновляем», потом «Готово: версия 2.4» и окно «Что нового».
