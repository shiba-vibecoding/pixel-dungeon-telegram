Метка забега `.pd-runtag.ranked | .replay | .seed | .unranked`: значок `run-tags.png` ×2, слово, рамка цвета метки (`currentColor`).

| Метка | Цвет | Когда |
| --- | --- | --- |
| зачёт | `--good` | забег проверяет сервер, он пойдёт в рейтинг |
| повтор | `#7ab8ff` | повтор подземелья дня — не в рейтинг |
| свой сид | `#c890ff` | забег с введённым сидом — не в рейтинг |
| без зачёта | `--ink-muted` | без проверки сервером |

- Окно смерти: под заголовком строка `.pd-runtag-line` — метка и пояснение.
- Меню игры: в подзаголовке `.pd-menu-sub` — метка, затем «Подземелье дня · гл. 7» или «Сид PIXEL-42 · гл. 4».
- `title` и `aria-label` — полное пояснение.
