Значки на ячейке предмета.

- `.pd-charge` — заряд артефакта (в рюкзаке и быстром слоте). Полный — `.full`, лиловый, кант мигает. Заряды жезла остаются текстом «2/3».
- `.pd-mark.ench` (искра, оружие) и `.pd-mark.glyph` (щит-руна, броня) — левый нижний угол, цвет в `--ench`. Новое (ещё не осмотрено) — `.new`, золотая точка. Неопознанное — цвет `ink-muted`. Проклятое — `--ench: var(--danger)` и череп справа сверху, как раньше.
- В карточке предмета — строка `.pd-ench-line` со значком, названием цветом зачарования и одной строкой эффекта.
- Таблица всех 17 зачарований, 13 глифов и 18 проклятий Shattered с цветами — в migration.md.
