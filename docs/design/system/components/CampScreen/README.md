Привал вместо формы с кнопками: сцена у входа в подземелье, в центре герой выбранного класса.

- **Сцена** — `PD.camp(el, { scene, season, hero, skin, effect })`. Слои: фон, мерцающие звёзды (вспышка крестиком раз в 9 с), пламя факелов и костра, герой, свет (`lighter`: ступенчатые кольца с дизерингом по краю), частицы (искры костра; снег зимой, листья осенью, падающая звезда летом; пылинки в пещере и зале).
- **Поверх** `.pd-camp-ui`:
  - карточка игрока `.pd-profile.framed`: портрет в рамке из Пиксель-Марта, имя, огонёк серии и «12 дней подряд», рекорд и забеги, заморозки и кубки;
  - значки по краям `.pd-camp-icon` 48×48 (подписи — в `aria-label` и `title`): слева задания (точка — есть новое) и почта (число писем), справа рейтинг, Пиксель-Март, настройки;
  - нижняя панель `.pd-camp-sheet` на градиенте: подземелье дня `.pd-daily.compact` (название, «Спуститься», правила дня — испытание красным, дар зелёным, «1 попытка»), «Продолжить», «Новая игра» + «Испытания».
- Под героем имя класса со стрелками ‹ ›: это и подсказка про свайп, и замена ему для тех, кто не листает.
- На низком экране сцена поднимается так, чтобы ноги героя стояли на 16 px выше панели (`cam.shift(y)`).
- Класс на сцене — для «Новой игры». «Продолжить» ведёт в сохранённый забег, его герой подписан на кнопке.
