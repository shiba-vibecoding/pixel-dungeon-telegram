Почта на 360–375 px: награда и «Забрать».

- Строка действий письма — на всю ширину письма (под значком тоже): `grid-template-areas: "ico head" "ico text" "act act"`.
- `.pd-letter-act { display: flex; flex-wrap: wrap; }`, награды `flex: 1 1 auto; min-width: 0`, кнопка `flex: none; margin-left: auto`. Влезают — одна строка; не влезают — кнопка сама переходит на следующую строку и прижимается вправо.
- Слишком длинная награда переносится внутри плашки (`.pd-gift { white-space: normal }`), без обрезки.
- Никаких `<br>`: перенос зависит от языка и ширины. Разделитель тысяч и «4 место» — неразрывный пробел (U+00A0).
