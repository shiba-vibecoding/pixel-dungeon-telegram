«Бестиарий» — пятая подвкладка «Каталога» в журнале. Подвкладки сделаны как полки Пиксель-Марта (`.pd-tabs.compact.shelf`): значок у каждой, подпись — только у выбранной. Иначе пять слов на русском не влезают в 360 px.

- Счётчик `.pd-cat-count`: «Встречено 25 из 66 · убито 287».
- Группы `.pd-best-group`: пять регионов («Канализация · глубины 1–4» … «Демонические залы»), «Боссы», «Задания» (зловонная крыса, гнолл-трюкач, огромный краб), «Всюду», «Редкие». В шапке `.pd-best-head` — название, глубины и «встречено/всего» справа; на узком экране глубины уходят на вторую строку.
- Сетка `.pd-best-grid`: `repeat(auto-fill, minmax(48px, 1fr))`, на 360 px — 5 столбцов. Клетка `.pd-best-cell` с портретом `.pd-mob` (×2) и числом убитых `.pd-best-n` в углу; 999+ дальше не растёт.
- Не встреченный — `.pd-best-cell.unseen` и `.pd-mob.silhouette`: силуэт своего же спрайта (маска из атласа) цветом `--mob-silhouette`. Имя скрыто: «Ещё не встречен», у боссов — «???».
- Снизу `.pd-best-detail`: портрет ×3 (`.pd-mob.x3`), имя, «регион · глубины · убито», описание. Не встреченный — силуэт, «где живёт» и «Встретьте его в подземелье…».
- Откуда числа: в Shattered это `Bestiary.encounterCount` (убито) и `seen`. Списки и порядок — `Bestiary.REGIONAL / BOSSES / UNIVERSAL / RARE`. Задания, мирные, союзники, ловушки и растения можно добавить такими же группами позже.
