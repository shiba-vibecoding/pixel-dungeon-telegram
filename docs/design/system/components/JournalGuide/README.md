Журнал → третья вкладка **«Памятка»** (`.pd-guide-window`).

- Список `.pd-guide-list`: строка `.pd-guide-row` — значок 40 px (`.pd-guide-ico`), заголовок, одна строка, шеврон. Непрочитанная — золотая точка после заголовка, прочитанная (`.read`) — тусклее. Сверху — «14 советов · прочитано N».
- 14 советов: голод, анх, проклятия, золото и лавки, мимики, чистота и очищение, колодцы, семена, счёт, испытания, цвета ловушек, тайники, опознание, улучшения.
- Страница совета: в шапке «‹ Памятка» (`.pd-back`) и крестик; крупный значок 56 px и заголовок (`.pd-guide-title`); текст, пункты `.pd-guide-points`, примечание `.pd-note`.
- **Цвета ловушек** `.pd-trap-legend`: 9 строк — образец `.pd-trapc` (настоящий кадр `terrain_features.png`, `--c` = цвет 0–8) на плитке пола, название семейства, что делают. Сработавшая — чёрная. Состав семейств сверьте с `color` в классах ловушек.
- **Чистота и очищение** `.pd-compare`: два столбца (на 360 px — один под другим), у каждого — зелье, «обычное / экзотическое» и три пункта.
