Окно героя, вкладка «Таланты» (`.pd-hero-window`), по образцу WndHero / TalentsPane из Shattered.

- Четыре яруса `.pd-tier`. В шапке «Ярус N», подпись (уровни или путь) и счётчик: «5/5» или золотой «свободно 2» (`.pd-tier-points.free`).
- Талант `.pd-talent` 56×66: значок 16×16 ×2 из `talent_icons.png` и точки `.pd-pips` (2 или 3). Состояния: `.zero` (ничего не вложено, значок приглушён), `.max` (золотой кант), `.selected` (открыт в карточке).
- Ярус 3 — таланты класса и выбранного пути; ярус 4 — способности брони. Закрытый ярус `.locked`: пустые места и строка, что нужно сделать.
- Карточка `.pd-talent-card`: значок, «Ярус 3 · Гладиатор», «1 из 3», уровни +1/+2/+3 (`.done`, `.next` в золотой рамке), «Улучшить» и остаток очков яруса.
- Пока есть свободные очки — «+» на кнопке героя (`.pd-talent-badge`, мигает раз в 1,2 с) и на вкладке (`.pd-tab-plus`).
