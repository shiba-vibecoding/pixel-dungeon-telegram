`?` (`.pd-help`) в шапке окна «Рейтинг» открывает «Правила доски» `.pd-rules`:

- **Очки** — как в оригинале: золото + уровень × глубина × 100, победа с амулетом ×2, каждое испытание +25%.
- **Места** — день: кубок за 1–3; неделя: медаль за 1–10; награды приходят в почту, когда доска закрывается.
- **Когда закрывается** — день в 00:00 UTC (03:00 МСК), неделя в ночь на понедельник; таймер под пояснением доски.
- **Равные очки** — выше тот, кто закончил забег раньше.
- **Что засчитывается** — только проверенные сервером забеги; забег без связи засчитается, когда она вернётся.
