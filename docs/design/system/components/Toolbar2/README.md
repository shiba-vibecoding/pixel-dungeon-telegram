Новый порядок нижней панели — `PD.demo.toolbar2(lang, n)` → `.pd-toolbar.tb2`:

**Ждать** · **Осмотреть** (если быстрых слотов нет) **или быстрые слоты** · **Искать** · **Рюкзак**

- Кнопки — флекс одной ширины, зазор 6 px; после «Ждать» и перед «Искать» ещё 6 px (`.wait { margin-right }`, `.gap { margin-left }`) — три группы: время, вещи, поиск и рюкзак.
- 4 слота (`.dense`): лишние 6 px убираются, иначе на 360 px кнопки уже 44 px. С ними — 44 px ровно.
- 6 слотов (`.q6`): слоты рядом сверху, внизу «Ждать · Осмотреть · Искать · Рюкзак».
- «Ждать» и «Искать» больше не стоят рядом. Значки `tool-wait2.png` (тёплый циферблат) и `tool-search2.png` (голубое стекло) отличаются ещё и цветом. Удержание «Ждать» — по-прежнему отдых.
