Герой на привале, кадры из листа героя (ряд 1):

- **Покой**: кадры 0,0,0,1,0,0,1,1 по секунде — дыхание; раз в 4,3 с на 140 мс глаза закрыты (чёрные пиксели глаз перекрашены цветом пикселя выше).
- **Касание**: кадры удара 13, 14, 15, 0 по 67 мс, 9 искр от руки и облачко `.pd-camp-bubble` с фразой класса (по кругу из трёх), 1,9 с.
- **Частые касания**: 4 касания за 2,5 с — герой отворачивается от костра, над головой мигает знак обиды, облачко «Ну хватит!». 3 с не отвечает: новое касание — «Я обиделся» / «Я обиделась».
- **Свайп** (больше 40 px по горизонтали или стрелки ‹ ›): за 260 мс герой темнеет до силуэта и сдвигается на 6 px, класс меняется, новый выходит из тени с другой стороны.
- **Облик**: лист героя заменяется листом из Пиксель-Марта. **Эффекты**: «Искры» — золотые искорки вокруг, «Светлячки» — четыре огонька по кругу, «Снег» — снегопад над героем.
- `prefers-reduced-motion`: оставьте дыхание и пламя, уберите сдвиг при свайпе и вспышки звёзд.
