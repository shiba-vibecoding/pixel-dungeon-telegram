Карточка артефакта: уровень ступенями до 10 (`.pd-art-level`, текущая ступень заполняется частично), заряд делениями (`.pd-charge-bar.seg`, `--v` и `--n`), строка состояния и кнопки действий.

- Полный заряд — `.full`: полоска цвета `charge-full`, строка «Заряжен полностью».
- В быстром слоте и в рюкзаке — маленькая полоска `.pd-charge` у нижнего края значка (4 px). С ней число и метка быстрого слота поднимаются; с прочностью она стоит над `.pd-dur`.
