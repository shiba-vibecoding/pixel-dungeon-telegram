- **Смазать дротики**: семена из рюкзака в ряд (с количеством), выбранное — в рамке; предпросмотр «Солнцетрав → 2 исцеляющих дротика» и эффект; «Смазать 2» и «Смазать все».
- **Очистить дротики**: смазанный → обычный, предупреждение, что семя пропадёт; «Очистить один», «Очистить все (N)», «Отмена».
- **Камень усиления**: вещь сверху, три варианта (`.pd-aug-opt`, radiogroup) с числами до и после: выгода зелёным, цена красным, текущий — чип «сейчас». Оружие — скорость или урон, броня — уклонение или защита.
