Алхимия без CSS-частиц: `PD.alchMount(root)` оживляет `canvas.pd-alch-pot` (котёл между ингредиентами и результатом), `canvas.pd-catalyst` и `canvas.pd-energy-pile`.

- Котёл: `data-mode="idle"` — кипит; `brew` — 6 кадров нагрева, «пуф» и снова кипит; `cata` — то же лиловое. Показ ×2, 64×64.
- Энергия: `PD.alchEnergy(window, вещи, счётчик, N)` — по 3 осколка от каждой вещи летят дугой к счётчику, счётчик на миг зеленеет, над ним «+N».
- Учебник: ненайденная страница `.pd-guide-lost` — рваный лист с замком, «Страница ещё не найдена», где искать, сколько найдено, силуэты рецептов «? + ? → ?».
