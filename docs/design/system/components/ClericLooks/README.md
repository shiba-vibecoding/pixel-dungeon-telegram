`PD.demo.heroFx(phone, { scene })`.

- **Союзник света** (`scene: 'light'`). В Shattered — `LightAllySprite`: спрайт героя случайного класса, `rm = gm = bm = 0`, `tint(1.33, 1.33, 0.8, 0.6)`, прозрачность 0,8, то есть плоский силуэт (204, 204, 122). На нашей тёмной карте он читается как грязно-оливковый, поэтому: плоский силуэт (255, 250, 200), прозрачность 0,85, вокруг — ступенчатый тёплый свет `#fff0aa` r = 13 (как свет костра на Привале), а раз в 1,6 с вверх уходят 3 искорки. Если хотите точь-в-точь как в Shattered — `tint(1.33, 1.33, 0.8, 0.6)`, без ореола.
- **Усиленный союзник** (сила многих, `CharSprite.State.GLOWING`): `tint(1.33, 1.33, 0.83, s)`, где s = 0,5 → 0,6 → 0,5 → 0,4 по 250 мс (в Shattered — плавный косинус); слабый ореол той же частоты.
- **Остаточный образ** Дуэлянтки (`scene: 'afterimage'`): тот же спрайт, прозрачность 0,6, без оттенка (как `AfterImageSprite`). Исчезает за 3 с: 0,48 → 0,36 → 0,24 → 0,12 → 0, по 600 мс.
- **Заклинание над героем** (`scene: 'spell'`): кадр `spell-sprites.png` над головой, появляется 200 мс (полупрозрачный, на 2 пикселя ниже), висит 800 мс, гаснет 0,66 → 0,33.
- Состояния Клирика в HUD: `<button class="pd-buff"><i class="cleric" style="--ix:N"></i></button>`, окно — `.pd-cbuff.large`.
