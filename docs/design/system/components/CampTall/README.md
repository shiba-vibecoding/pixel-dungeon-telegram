Высокие телефоны (430×932, 412×915, 360×800).

- Ноги героя — всегда на 16 px над нижней панелью: `shift = верх панели − 16 − 129 × 4`, теперь и вниз (до высоты дорисовки), а не только вверх.
- `PD.camp(el, { fill: true })` дорисовывает сцену до краёв `el`: сверху — самым тёмным цветом первой строки (небо со звёздами, свод пещеры, тёмный потолок зала), снизу — отражением земли, по бокам — отражением краёв (на 412–440 px это 2–8 пикселей сцены).
- Пересобирайте фон при смене размера (поворот, клавиатура).
