Котёл (`.pd-alch-window`), по образцу AlchemyScene.

- В шапке счётчик энергии `.pd-energy` (кристалл и число, цвет `energy`).
- Ряд `.pd-alch`: три ячейки ингредиентов (пустая — «+»), стрелка (`.ready` — золотая, если рецепт сложился), ячейка результата `.out` (`.unknown` — «?» поверх силуэта, если исход случайный).
- Под рядом название результата и цена в энергии; если энергии мало — `.pd-alch-cost.short`, «Сварить» выключена.
- «Превратить в энергию» открывает выбор вещей `.pd-alch-pick`: у каждой «+N» энергии, выбранные в голубой рамке, итог «Получите +9».
- «Рецепты» — учебник: страницы прокручиваются вбок (`.pd-guide-pages`, ненайденные с замком), рецепт `.pd-recipe` — значки ингредиентов, «+», энергия, стрелка, результат, подпись; «В котёл» кладёт ингредиенты из рюкзака.
