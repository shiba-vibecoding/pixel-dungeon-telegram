Три платных привала из Пиксель-Марта, та же композиция: где стоит герой, костёр и вход, не меняется, меняется окружение и свет.

- **Пещера с кристаллами** — кристаллы голубые и лиловые, их свет медленно пульсирует; голубое свечение в проходе; в воздухе поднимаются пылинки.
- **Тюремный двор** — зубчатая стена на фоне неба, окна с решёткой светятся тёплым, ворота с поднятой решёткой, два факела, бочка.
- **Зал гномьего города** — колонны, знамёна с гербом, три светильника, ковёр к лестнице; золотые пылинки.
