Обучение по шагу `.pd-coach`: всё, кроме нужного места, затемнено (`box-shadow` рамки на 9999 px), вокруг места — золотые уголки, раз в секунду расходятся на 3 px.

- Облачко `.pd-coach-bubble` встаёт под местом, если оно в верхней половине экрана, и над ним — если в нижней. Хвостик смотрит на место (`--tail`).
- В облачке: название, «Шаг N из 4», одна-две строки, «Пропустить обучение» (тихая) и «Дальше»; на последнем шаге — «Понятно» (основная). Точки шагов внизу.
- Шаги: враг (крыса), лестница вниз, рюкзак, быстрый слот. Шаг закрывается и сам, если игрок сделал то, о чём он.
