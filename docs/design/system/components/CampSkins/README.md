Облики Пиксель-Марта для Дуэлянтки и Клирика — пепельный, королевский, теневой. Листы героев 256×128 с той же раскладкой, аватары в `avatars-skins.png`. На привале облик меняет ряд героя (`camp-heroes.png`, ряды 10–15), портрет в карточке игрока берёт аватар облика.

Сцена открывается на герое сохранённого забега. Свайп выбирает класс для «Новой игры», а «Продолжить» всегда ведёт в сохранённый забег, и на кнопке подписан его герой.
