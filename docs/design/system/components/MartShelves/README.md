Пять полок Пиксель-Марта: Облики, Привалы, Эффекты, Рамки, Меценат — `.pd-tabs.compact.shelf`.

- Каждая вкладка — значок 32 px (`.pd-tab-ico.skin | camp | effect | frame | patron`) и подпись в `<span>`.
- Подпись видна только у выбранной вкладки (она шире: `flex-grow: 2.6`), остальные — значок; подпись у них в `aria-label` и `title`. Так все пять влезают от 360 px на русском и английском, без сжатия одной вкладки.
- Невыбранный значок серый, выбранный — золотой с подчёркиванием.
- Полка «Привалы»: открытки `.pd-camp-card` (66×48 ×2) вместо кропа сцены; «У входа» — «Бесплатно» и «Стоит»; на карточке короткое имя («Тюрьма»), в окне полное («Тюремный двор»).
