Выбор пути мастерства (после маски Тенгу) и способности брони (после короны короля гномов). Карточки `.pd-pick`: картинка, имя, описание, таланты, которые откроет выбор, «Выбрать».

- Путь — `.pd-picks.two`: портрет героя и значок пути ×3 на подложке с отсветом `--glow`; «Подробнее» открывает полное описание.
- Способность — 3 карточки: значок способности ×4 (64 px) слева, справа текст, внизу «Выбрать» и три таланта яруса 4.
- Внизу тихая «Решу позже»: выбор не торопит.
