Эффекты на карте, `PD.demo.mapFx(phone, o)` поверх карты:

- **Призматическое отражение** — своя фигура (`prismatic.png`): силуэт героя из радужного стекла, белые глаза, тёмная фиолетовая кромка; ряды — фазы цвета, 120 мс.
- **Метка союзника** — сердечко `ally-heart.png` над головой (цвет `ally`), покачивается раз в 400 мс. Для крупных союзников — то же сердечко, без обводки силуэта.
- **Призрак-спутник** (засохшая роза) — призрак с прозрачностью 0,82, качается на 2 px, вокруг голубой свет r = 1,6 клетки, `rgba(150,210,255,.22)`, мерцает ±0,06.
- **Эфирные цепи** — звенья `chain-link.png` выстраиваются от героя к цели за 600 мс, наконечник `chain-hook.png`, на конце — голубая вспышка; потом цель тянется.
- **Снаряды палочек** — `wand-bolts.png`, 12 видов, шлейф из 4 квадратов цвета палочки. Лучи (разрушение, призматический свет) остаются лучами, их цвет — как у снаряда.
- **Опасность** `.pd-danger` справа под HUD: череп и число врагов, которые видят героя. Касание — следующая цель (красная рамка `.pd-danger-ring`). Новый враг — 3 вспышки `.new`.
