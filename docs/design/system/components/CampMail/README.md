Окно «Почта» `.pd-mail-window`. Письмо `.pd-letter`: значок (кубок, медаль, значок сезона), заголовок, дата, текст, награды `.pd-gift` и «Забрать».

- Непрочитанное — золотая точка в углу (`.unread`). Забранное — `.claimed`: ячейка темнее, вместо кнопки «Получено» с галочкой.
- Первое незабранное письмо — с основной кнопкой, остальные — с обычной. Внизу «Забрать всё» и срок хранения.
- Пустая почта объясняет, откуда придут письма. На значке почты — число незабранных.
