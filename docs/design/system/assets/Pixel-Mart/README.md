Новая графика Пиксель-Марта в сетке спрайтов: один пиксель = `--u`. Цвета зашиты в файлы.

- `icon-stars.svg` 7×7 + обводка `void` — звезда цены (звёзды Telegram), рядом с числом цвета `price`.
- `icon-patron.svg` 9×9 + бронзовая обводка — звезда покровителя: длинный верхний луч и белый блик, чтобы не путать со звездой опыта.
- `icon-lock.svg` — замок на товаре, который открывается значком. `icon-season.svg` — снежинка сезонного товара, цвет `season`.
- `frame-bronze.png`, `frame-gold.png`, `frame-shadow.png`, `frame-patron.png` — рамки портрета 14×14, 9-slice со срезом 4, без заливки.
- `badge-patron.png` — значок «Меценат» 16×16 на рамке значков `badges.png`: синий фон, золотая звезда.

**v20 — значки полок** (`tab-skin`, `tab-camp`, `tab-effect`, `tab-frame` 16×16, показ ×2; у «Мецената» — `icon-patron.svg`). Золотые; у невыбранной вкладки CSS делает их серыми (`grayscale` + `brightness .62`).
