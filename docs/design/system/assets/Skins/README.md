Перекраски листов героев для Пиксель-Марта. Каждый лист — 256×128, те же кадры 12×15 и ряды уровней брони (0 — без брони … 6 — броня класса), что у `warrior.png`, `mage.png`, `rogue.png`, `ranger.png`.

- `*-ash.png` — «Пепельный»: броня почти серая (насыщенность ×0.32), волосы пепельные.
- `*-royal.png` — «Королевский»: металл и светлая ткань в золото, цветная ткань и кожа в пурпур, волосы свои.
- `*-shadow.png` — «Теневой»: оттенки брони сдвинуты к тёмному фиолетовому, волосы почти чёрные.
- Кожа (#dcb497, #b89778, #ffdabf, #855938, #be7f59, #ffba8f) и глаза (#000000) не меняются ни в одном облике.

**v19:** `duelist-ash/royal/shadow.png`, `cleric-ash/royal/shadow.png` — те же правила перекраски (кожа и глаза не меняются; у Дуэлянтки тёмная кожа тоже сохранена). `avatars-skins.png` 144×32 — аватары обликов: 0–2 Дуэлянтка (пепельная, королевская, теневая), 3–5 Клирик. Скрипт перекраски — `tools/art/skins.py` в архиве.
