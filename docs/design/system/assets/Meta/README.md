Иконки для «Испытаний» и «Журнала», 16×16, без сглаживания, на прозрачном фоне. Нарисованы в стиле спрайтов Pixel Dungeon 1.9: обводка `#000`, палитра предметов и тайлов.

- `challenges.png` — 112×16, по порядку Challenges.java: на диете, вера — мой доспех, фармакофобия, бесплодная земля, разум роя, во тьму, запретные руны. Те же иконки лежат по одной: `challenge-*.png`.
- `journal.png` — 176×16: колодцы здоровья, знания и превращений, жертвенная комната, алхимический котёл, сад, ожившая статуя, привидение, мастер палочек, тролль-кузнец, бес. Колодцы, котёл, сад и статуя — тайлы `tiles0.png`, жители — их листы.
- `icon-prefs.png` (PREFS) и `icon-challenge-off/on.png` вырезаны из `icons.png` оригинала. `icon-chevron.png` и `icon-external.png` — знаки строк-ссылок.
- `cursor.png` 12×18 и `cursor-x2.png` 24×36 — пиксельный курсор для монитора: `cursor: url(cursor-x2.png) 0 0, default` (при `--ui: 2` — сделайте ×4 так же, без сглаживания). `icon-book.png` — значок журнала (книга из `items.png`, 82), `icon-resume.png` — «идти дальше», те же стрелки, что рисует `mapui.ts`.
- `gestures.png` 48×96 — схемы жестов для карточки обучения, 6 строк по 3 кадра 16×16: нажмите, удерживайте, перетащите, бросьте, ЛКМ, ПКМ. Раскладка и длительности — `gestures.json`. `pointer.png` 16×16 — золотая стрелка вниз; на другие стороны её поворачивают.


**v24:** в `journal.png` колодцы, котёл, сад и статуя — тайлы канализации Shattered (вода колодцев подкрашена: здоровье красная, знание золотая, превращение фиолетовая); призрак, мастер палочек, кузнец, бес уже были Shattered. `journal-*.png` — те же клетки по одной (в игре не грузятся).
