Листы анимаций карты для `packages/client/public/assets/world/`. Каждый PNG лежит рядом с атласом JSON того же имени: `animations.<key>.frames[]` — `{ x, y, w, h, ms }`. Если у последнего кадра `ms: 0`, анимация на нём останавливается.

- `doors0..4.png` — дверь (4 кадра, 70 мс), запертая дверь (140, 180), горящая баррикада (150, 150, 180), по региону.
- `chests.png` — сундук, запертый и хрустальный сундук (90, 110, 160), гробница (110, 140, 180), мимик (80, 90, 110, 130), кости (140).
- `grass0..4.png` — трава качается 5 наклонами (ветер 220 мс, проход героя 80 мс), примятие (70, 90), лист 16×8 с шестью травинками.
- `feedback.png` — рамка хода и атаки, точки пути, крестик «нельзя».
- `glint.png` — искра на вещи, свечение снизу, монетка.
- `coop.png` — стрелка к товарищу за краем и кольцо, портреты 10×10, метка «сюда», 8 эмоций, огонёк над павшим.
- `splash.png` — брызги, круги на воде, мокрые следы, пыль.
- `ambient0..4.png` — жизнь региона (капли и пузыри, факел, жила, фонарь и дым, лава и угольки), колодец, жертвенник, 8 ловушек.
- `fog0..4.png` — бесшовный туман 64×64; `light.png` — маска света.
- `ui-map.png` — значки кнопок карты (обычные и нажатые) и 5 эмблем регионов 32×32.

Перерисованы из оригинальных тайлов Pixel Dungeon 1.9 (Watabou, GPL-3.0) в их палитре.


**v24:** `grass0–4` — качание из тайла RAISED_HIGH_GRASS (122) региона со сдвигом от корней (±3 px наверху), примятие кончается на GRASS (2), листья в цветах травы региона. `doors0–4` — RAISED_DOOR 112 → OPEN 113 (створка сжимается к петле), LOCKED 114 (замок вспыхивает) → 113, BARRICADE 121 (огонь прежний) → EMBERS 3. `chests.png` — кадр 0 = клетка `items.png` Shattered (CHEST 36, LOCKED 37, CRYSTAL 38, TOMB 34, BONES 32), затем щель света, крышка над кладом, пустой сундук. Туман, свет, брызги, искры — без изменений. Ряд «8 ловушек» в `ambient*` не используется с ловушками Shattered.
